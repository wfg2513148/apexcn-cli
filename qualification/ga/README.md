# 0.9 GA 候选激活与资格资产

这里保存 0.9 激活前必须冻结的机器可读契约：

- `public-surface-v1.json`：从当前可执行文件、command manifest、Schema registry、workflow goal 和源码 API 路径生成的公开面；
- `support-matrix-v1.json`：全部已发布稳定 1.x 起点、平台和恢复/回滚阶段；
- `qualification-contract-v1.json`：200 题评分、独立 validator、隔离写清理和独立安全审查契约。

这些文件只证明 denominator 和执行边界已经冻结。它们本身不证明资格通过。实际候选仍须提供独立首次尝试结果、完整矩阵、供应链验证、安全审查和零残留证据。
